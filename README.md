# haitrans

## Định dạng tệp đầu ra

Ứng dụng hỗ trợ các phần mở rộng chuẩn: `.txt`, `.docx`, `.pdf`, `.md`, `.tex` và `.odt`.
DOCX được tạo thành tài liệu OpenXML; ODT và PDF được chuyển đổi từ nội dung dịch bằng LibreOffice.
Để xuất ODT/PDF, cần cài LibreOffice và để lệnh `libreoffice` hoặc `soffice`
trong `PATH`.
